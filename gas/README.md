# Google Sheets — приём отчётов PL/SQL-тренажёра

## Быстрая настройка

1. Создайте Google-таблицу (можно пустую).
2. **Расширения → Apps Script** — вставьте содержимое [`Code.gs`](Code.gs).
3. **Развернуть → Новое развёртывание → Веб-приложение**
   - Выполнять как: **Я**
   - Доступ: **Все**
4. Скопируйте URL веб-приложения в [`js/report.js`](../js/report.js):

```javascript
endpoint: 'https://script.google.com/macros/s/ВАШ_ID/exec',
```

5. Откройте тренажёр, пройдите ident, сделайте попытку «Проверить» — в таблице появятся листы **Sessions**, **Attempts** и **Аналитика**.

6. Чтобы пересчитать дашборд вручную: меню **Тренажёр → Обновить аналитику** (или запустите `refreshAnalytics` в Apps Script).

## Листы

| Лист | Содержимое |
|------|------------|
| **Sessions** | Одна строка на каждую отправку: студент, статус, время, агрегаты, JSON-поля |
| **Attempts** | Одна строка на каждую попытку «Проверить»: код, балл, критерии, ORA |
| **Аналитика** | Дашборд: сводка, сложность заданий, статистика по ученикам, графики (обновляется автоматически) |

### Лист «Аналитика»

- **Сводка** — учеников, % завершения, среднее время, попытки, средний балл.
- **Сложность заданий** — % сдачи, средние попытки и время; сверху — самые трудные.
- **По ученикам** — задания, % успеха, попытки, время, балл (лучшая сессия на человека).
- **Графики** — % сдачи и баллы по заданиям, индекс сложности, pie «завершили / в процессе», bar % успеха по ученикам.

## Триггеры отправки из тренажёра

- **complete** — зачтено последнее (5-е) задание
- **leave** — закрытие вкладки до завершения (`sendBeacon`)
- **manual** — кнопка «Отправить преподавателю» в модалке «Мой отчёт»

Fallback: кнопка «Скачать отчёт» → JSON-файл с тем же payload.
